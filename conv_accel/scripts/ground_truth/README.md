# Ground-truth deblur study

Синтетический тест: резкая сцена → точный рендер смаза по траектории
`p(u) = c + uT + R(uΦ)(p − c)` → блочная винеровская деконволюция с
локальной PSF. Результаты и выводы — в `docs/ground_truth_deblur.md`.

## Запуск

```bash
python3 gt3a.py    # сцена, рендер, проверка модель-vs-рендер
python3 gt3e.py    # свип по D, WOLA-деконволюция, crops
```

`gt3a.py` создаёт `sharp3.npy`, `blur_t3.npy`, `blur_f3.npy`; `gt3e.py`
их читает. Нужны только `numpy` и `opencv-python`.

## Важно

`cv2.warpAffine` по умолчанию считает `dst(x) = src(M⁻¹x)`. Поэтому в
рендер передаётся **прямая** матрица `M = W_u`; если передать обратную,
размытие пойдёт в противоположную сторону и PSF перестанет ему
соответствовать (именно эта ошибка была в первой версии).
