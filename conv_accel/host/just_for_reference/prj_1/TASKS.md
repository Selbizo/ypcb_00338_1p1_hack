## Описание проекта
Проект для заказчика. Реализация контура цифровой стабилизации видео по вычислению разреженного оптического потока Люкаса-Канаде. Алгоритм внедряется в контур гиростабилизированного подвеса камеры для отработки возмущений, которые не способна подавить механическая часть. Запускается на ПК и Banana Pi CM4, поддержка GPU OpenCL-вычислений.
